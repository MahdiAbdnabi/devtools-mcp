Unix timestamp

Converts Unix epoch seconds or milliseconds to dates, ISO 8601 text to epoch values, or shows the current time.

MCP name encoding__timestamp · tool id encoding.timestamp · Encoding · read-only

  • When to use it
  • Inputs
  • Options
  • Outputs
  • Diagnostics
  • Limits
  • Examples (5)

When to use it

  • A log or database holds 1709647629 and you want the date.
  • You need the epoch value of a date for a query or a test.
  • You want to see a moment in another time zone, with daylight saving handled.

When another tool fits better

  • JWT decoder (no verification) (encoding__jwt): The numbers are inside a JWT; the decoder labels them.
  • C# date format (datetime__csharp): You want a date written with a format pattern.

Inputs

text text Values (one per line)
Values, one per line: epoch numbers (to-date) or ISO 8601 date-times (to-epoch). Not used by mode now. A file path can be given in textFile instead.
One value per line; not used in mode now.
Example: 1709647629

Options

mode enum, default to-date Mode
to-date reads epoch numbers, to-epoch reads ISO 8601 text, now prints the current time.
  • to-date: epoch numbers to dates
  • to-epoch: ISO 8601 text to epoch values
  • now: the current time
unit enum, default auto Unit
to-date: auto reads values below 1e11 as seconds.
  • auto: values below 1e11 are seconds, larger ones milliseconds
  • seconds: always seconds
  • milliseconds: always milliseconds
timezone string, default UTC Time zone
UTC, local (the zone of this computer) or an IANA name.
UTC, local or an IANA name. In to-epoch it is the zone of values written without an offset.
Example: America/New_York

Outputs

result table
One row per value: Input, Interpreted as, UTC, In zone, Epoch s, Epoch ms.

Diagnostics

Messages the tool can return, last in the result, as severity CODE: message (line, column). Codes that any tool can return are listed in the overview.

E_TS_NUMBER error in an example below
A line in to-date mode is not a number.
E_TS_ISO error
A line in to-epoch mode is not ISO 8601.
E_TS_RANGE error
The value is outside the supported range (about 275000 years either side of 1970).
E_TS_ZONE error
The time zone is not known.
E_TS_TOO_MANY_LINES error
Too many lines for one run.
W_TS_DST_GAP warning in an example below
A local time falls in a daylight-saving gap and does not exist; it was moved forward.
W_TS_DST_AMBIGUOUS warning
A local time happens twice (the clocks went back); the earlier one was used.
W_TS_PRECISION warning
Digits beyond milliseconds were dropped.
I_DIAG_DROPPED info
More warnings of one kind were found than are listed.

Limits

  • Precision is one millisecond.
  • auto reads values below 1e11 as seconds: a millisecond value from early 1973 or before would be read as seconds; set unit for such values.
  • Mode now changes on every call.
